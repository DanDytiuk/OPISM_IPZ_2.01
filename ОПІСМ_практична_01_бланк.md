### A.3. Запит до служби доменних імен

*Windows: `Resolve-DnsName ВАШ_ДОМЕН`*

**Команда (перше виконання):**

```
Resolve-DnsName haskell.org
```

**Вивід:**

```
Name                                           Type   TTL   Section    IPAddress
----                                           ----   ---   -------    ---------
haskell.org                                    A      600   Answer     142.93.179.24
```

**Команда (повторне виконання через 5–7 хвилин):**

```
Resolve-DnsName haskell.org
```

**Вивід:**

```
Name                                           Type   TTL   Section    IPAddress
----                                           ----   ---   -------    ---------
haskell.org                                    A      600   Answer     142.93.179.24
```

**Зафіксовані значення:**

| Параметр | Перше виконання | Повторне виконання |
|---|---|---|
| Час виконання (год:хв) | 12:40 09.09.26 | 12:55 09.09.26 |
| IP-адреса | 142.93.179.24 | 142.93.179.24 |
| Значення TTL | 600 | 600 |

> Якщо друге значення TTL виявилося більшим за перше — це нормально: кеш резолвера встиг оновитися. Зафіксуйте як є.

## Контрольні питання

**1. Скільки рядків діагностичного виводу передує отриманню даних сторінки (завдання A.1)? Наче 13, якщо рахувати до Request completely sent off **

> 

**2. Які рядки наявні у виводі A.1 і відсутні у виводі A.2? Чим це зумовлено? 
* schannel: disabled automatic use of client certificate
* ALPN: curl offers http/1.1
* ALPN: server accepted http/1.1 

Це зумовлено тим що у А1 використовується https а у А2 - http**

> 

**3. Звідки у виводі з'явилося значення `443`, якщо його не було вказано в адресі? 443 порт по дефолту використовується для передачі даних за допомогою https** 

> 

**4. Як змінилося значення TTL між двома запитами (A.3)? Що означає це число? В моєму випадку воно тільки зменшувалося якщо кидати запрос постійно, почекав 10 хвилин показало TTL = 600 , TTL - час життя пакету у секундах**

> 

**5. Чим відрізняються між собою три причини помилок із завдання A.5? Сформулювати кожну однією фразою. **
